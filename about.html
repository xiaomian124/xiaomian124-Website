隐私政策

最后更新：2026 年 10 月 14 日

我们收集什么

当你在 留言板 发表留言时，本站会记录：

  • 昵称：你填写的显示名称
  • QQ 号：仅用于显示头像，不填也可以
  • 留言内容：包括支持 Markdown 格式的文本
  • IP 哈希值：将你的 IP 加密后存储，用于限流和防止滥用，无法反推真实 IP

我们如何使用

  • 展示你的留言给其他访客
  • 防止刷屏和恶意提交
  • 让你能删除自己的留言（通过 IP 哈希识别）

我们不做什么

  • 不收集你的邮箱、电话号码、真实姓名
  • 不存储明文 IP 地址
  • 不将数据用于广告或商业目的
  • 不将数据出售或分享给第三方

数据存储

所有留言数据存储在 Cloudflare 的 D1 数据库 。 本站使用 Cloudflare 的全球 CDN 服务，访问时你的请求会经过 Cloudflare 的节点。

浏览器本地存储

本站使用浏览器的 localStorage 保存以下信息，仅存储在你的设备上，不会上传到服务器：

  • 主题偏好
  • 背景图开关
  • 隐私政策已读版本号

清除浏览器数据即可删除这些记录，但不影响网站的正常使用。

站内搜索

首页和部分页面的搜索功能在你的浏览器本地运行， 搜索关键词不会上传到服务器，也不会被记录。 如果点击“用搜索引擎搜索”，会跳转到 Bing / Google / 百度， 这些平台的搜索行为由各自的隐私政策管辖。

背景图

本站使用 Bing 每日图片作为背景，通过自己的服务器代理获取。 图片请求经过 Cloudflare 网络，Bing 不会直接获取你的 IP 地址。

好友链接

“好友”页面仅展示我手动整理的外部链接和头像。 点击“访问主页”会跳转到第三方网站，这些网站的隐私政策由其运营方负责。

RSS 订阅

本站提供 RSS 订阅源 ， RSS 阅读器获取该文件时不涉及任何用户数据上传。

更新提示

当隐私政策有重大更新时，网站顶部会显示提示条。 你点击“了解”或“查看”后，浏览器会记录一个版本号， 避免重复提示。这个记录仅保存在你的设备上。

你的权利

  • 可以随时删除自己发表的留言
  • 可以要求删除所有与你相关的数据，通过 联系我 来删除
  • 可以随时清除浏览器本地存储的数据

政策变更

如果本政策有重大变更，会在此页面更新“最后更新”日期。 继续使用本站即表示你同意最新版本的政策。

开源

这个网站的源码全部开源在 GitHub， 欢迎参考或提 Issue。如果对你有帮助，也可以到 留言板 说一声。
