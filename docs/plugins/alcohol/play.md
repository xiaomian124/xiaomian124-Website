## 详细玩法流程

### 第一步：获取基础工具

**收割剪刀**（工作台合成）


- 收割剪刀专门用于采集以下方块，并会在**保留原版掉落**的基础上**追加插件掉落**：
  - **成熟小麦** → **大麦** 或 **燕麦**
  - **矮草丛** → **野生荨麻** 或 **玉米种子**
  - **丛林树叶** → **啤酒花** 或 **丛林红/白葡萄种子**
  - **橡树树叶** → **红/白葡萄种子** 或 **樱桃**
  - **金合欢树叶** → **热带草原红/白葡萄种子**
  - **云杉树叶** → **针叶林红/白葡萄种子**

### 第二步：种植农作物

#### 玉米

1. 用**收割剪刀**打**矮草丛**，有几率获得**玉米种子**。
2. 手持玉米种子右键**耕地**，开始种植。
3. 玉米植株共有 **4 个阶段**：
   - **阶段 1**：小麦种子
   - **阶段 2**：蕨
   - **阶段 3**：深色橡树树苗
   - **阶段 4**：树苗上方长出**玉米**
4. 每阶段自然生长耗时约 3~7 分钟，也可用**骨粉**立即催熟。
5. **蜜蜂授粉**：带花粉的蜜蜂飞过玉米植株可提升生长。
6. 右键/破坏阶段 4 的**玉米头颅** → 获得 **玉米**，植株回到阶段 3 继续生长。
7. 同一株玉米最多采集 **3 次**，之后下方的树苗会变成**枯萎的灌木**。
8. 破坏玉米植株的**底部方块**，会一次性掉落玉米种子。

**玉米的用途**：工作台 1 玉米 → 5 玉米粒；玉米粒放入**烟熏炉** → 烘干的玉米粒 → 用于酿造威士忌。

#### 大麦与燕麦

- 用**收割剪刀**打**成熟小麦**，有几率掉落**大麦**或**燕麦**
- 放入**烟熏炉**烧炼：
  - 大麦 → **烘干的大麦**
  - 燕麦 → **烘干的燕麦**

#### 葡萄（8 种，按生物群系区分）

| 葡萄种类 | 种子来源 | 种植方式 | 成熟形态 |
|---------|---------|---------|---------|
| 红葡萄 | 橡树树叶 | 草方块/泥土等 | 甜浆果丛 |
| 白葡萄 | 橡树树叶 | 草方块/泥土等 | 甜浆果丛 |
| 热带草原红葡萄 | 金合欢树叶 | 草方块/泥土等 | 甜浆果丛 |
| 热带草原白葡萄 | 金合欢树叶 | 草方块/泥土等 | 甜浆果丛 |
| 丛林红葡萄 | 丛林树叶 | **原木侧面** | 藤蔓 |
| 丛林白葡萄 | 丛林树叶 | **原木侧面** | 藤蔓 |
| 针叶林红葡萄 | 云杉树叶 | **两个栅栏堆叠** | 深色橡树树叶 |
| 针叶林白葡萄 | 云杉树叶 | **两个栅栏堆叠** | 深色橡树树叶 |

**种植细节**：
- **地面葡萄**：右键草方块顶面 → 生成甜浆果丛（age=0）。可用骨粉催熟到 age=2（成熟），最多长到 age=2。成熟后会冒粒子
- **藤蔓葡萄**：手持种子右键原木**侧面** → 生成藤蔓，仅贴原木那一面。可用骨粉催熟，每次推 1 阶段，3 次成熟。成熟后仍是藤蔓，会冒粒子。
- **栅栏葡萄**：需**上下两个栅栏**。右键下面栅栏 → 上面的栅栏变深色橡树树叶。骨粉催熟 3 次后，深色橡树树叶→**丛林树叶**（成熟的标志），会冒粒子。

**食用**：吃下葡萄时有15% 概率吃出葡萄种子。

**采集**：右键成熟的葡萄植株 → 掉 **葡萄**。同一株最多采集 **8 次**：

- 地面葡萄：8 次后变**枯萎的灌木**
- 藤蔓葡萄：8 次后藤蔓**直接被破坏**
- 栅栏葡萄：8 次后恢复**原栅栏方块**

#### 樱桃

1. 用**收割剪刀**打**橡树树叶**，有几率获得**樱桃**。
2. 手持樱桃右键**草方块顶面** → 生成**橡树树苗**。
3. 树苗用骨粉或自然生长长成**橡树**。
4. 树上的部分橡树树叶会**随机变成丛林树叶**（表示结果）。
5. 右键**成熟的丛林树叶** → 掉 **樱桃**（20% 概率掉腐烂樱桃），叶子变回橡树树叶。
6. **挖掘树干** → 整棵树凋落，所有树叶掉落木棍/樱桃/腐烂樱桃。
7. **食用**：
   - 樱桃：恢复 2 饥饿 + 1.4 饱和度
   - 腐烂樱桃：恢复 1 饥饿 + 1.0 饱和度，附带 **中毒 I 10 秒**

### 第四步：机器使用详解

#### 烹饪锅（炼药锅材质）

- **放置**：右键放置
- **加水**：
  - 蹲下右键手持**水桶** → 直接填满 3/3
  - 蹲下右键手持**水瓶** → 每次 +1 层（最多 3 层）
- **打开 GUI**：普通右键。
- **GUI 布局**：
  - 6 个原料格 + 1 个输出格 + 1 个倒计时头颅 + 热源指示 + 储水指示
- **烹饪条件**：
  - 下方必须有**营火/火方块**
  - 锅内必须有**储水**（每次烹饪消耗 1 层）
- **配方**：1 糖 + 1 水桶 + 1 小麦 → **酵母**（30 秒）

#### 酿造炉（烟熏炉材质）

- **打开 GUI**：右键
- **GUI 布局**：
  - 3 个原料格 + 1 个输出（棕色玻璃显示酒类型+品质）+ 倒计时头颅 + 水桶槽 + 燃料槽 + 气压时钟
- **酿造条件**：
  - 3 个原料匹配配方
  - 水桶槽有水桶
  - 燃料槽有煤炭/木炭（每个配方消耗 3 个）
- **酿造时间**：每瓶 60 秒
- **气压系统**：
  - 气压从 0% 上升到 100%（**顶峰**）
  - 气压 ≥ 100% → 酿造暂停，冒出 **村民生气粒子** + **火焰音效**
  - 玩家需要**蹲下右键**进行泄压 → 气压平滑降到 20%，冒出营火烟雾
  - 不泄压超过 10 秒 → **品质降一级**（高品质→优秀→良好→…→非常差）
- **取酒**：手持**玻璃瓶**蹲下**左键** → 获得成品酒
- **输出队列**：可堆叠至 64 个，超过后停止酿造等待玩家取

#### 苹果压榨器（织布机材质）

- **打开 GUI**：右键
- **两个独立流程**：
  1. **苹果 → 苹果泥**（15 秒/个）
  2. **苹果泥 + 玻璃瓶 → 苹果汁**（15 秒/个）
- **输出队列**：最多 64 个

#### 陈酿桶（木桶材质）

- **打开 GUI**：右键
- **GUI 布局**：
  - 酒原输入（放入酿造炉产物）+ 3 个原料 + 玻璃瓶 + 酒输出 + 酒余量 + 两个倒计时头颅
- **倒酒**：放入酒 → 酒量 +25%（最多 100%），返还玻璃瓶
- **陈酿时间**：5 分钟
- **消耗**：每个配方消耗**指定百分比**的酒量
- **26 种陈酿酒**：如蜂蜜酒、苹果酒、Pinot Noir、猫娘特调等，每种都有独特的材料与效果
- **倒掉**：蹲下**左键**陈酿桶 → 清空酒量

#### 葡萄藤盆（堆肥桶材质）

- **放置葡萄**：手持葡萄右键 → 堆肥层 +1（最多 6 层）
- **不混用**：一旦放入某类葡萄，其它类型无法放入
- **跳到顶**：站上面**跳 3 次** → 层数到顶（8 层），可取汁
- **取汁**：蹲下右键手持**玻璃瓶** → 获得**葡萄汁**，共可取 2 次

#### 吧台音乐播放器（唱片机材质）

- **打开 GUI**：右键
- **GUI 布局**：
  - 唱片显示（歌曲名+作者）+ 上一首/下一首/播放暂停按钮
- **播放**：点击播放 → 16 格内的玩家可听到音乐
- **暂停**：点击暂停 → 暂停音乐
- **循环模式**：点击唱片 → 切换列表循环/单曲循环
- **歌曲**：将 `.nbs` 文件放入 `src/main/resources/songs/` 加载
