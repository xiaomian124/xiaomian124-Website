## 配置

### 数据文件说明

| 文件 | 用途 | 保存时机 |
|------|------|---------|
| `data.yml` | 保存烹饪锅、酿造炉、苹果压榨器、陈酿桶、葡萄藤盆、玉米、葡萄、樱桃树等状态 | 每 5 分钟自动保存 + 关服保存 |
| `effects.yml` | 保存玩家特殊效果、actionbar 显示、隐藏蜘蛛网坐标 | 效果变化时立即保存 + 每 30 秒兜底 |
| `songs/` | 存放 `.nbs` 歌曲文件，自动加载到吧台音乐播放器 | 只读 |

### 歌曲添加

1. 用 [Note Block Studio](https://noteblock.studio/) 制作或下载 `.nbs` 文件。
2. 将文件放入 `plugins/Alcohol/songs/`。
3. 输入 `/alcohol reload` 或重启服务器。
4. 打开吧台音乐播放器 GUI，即可看到新歌。

### 数据备份建议

| 文件 | 频率 |
|------|------|
| `data.yml` | 每周 |
| `effects.yml` | 每周 |
| `songs/` | 一次性（除非手动修改） |

::: danger 警告
- **不要手动编辑 `data.yml` / `effects.yml`**，YAML 格式错误会导致数据加载失败。
- 升级插件时旧数据自动兼容，无需清空。
- 删除 `data.yml` 会丢失所有容器与植物数据，请谨慎操作。
:::
