# 指南

这里是一些通用的使用说明，适用于我的所有插件、模组或其他等项目。

## 插件和模组的区别

在开始之前，先搞清楚一件事：

| 类型 | 运行位置 | 玩家需要装吗 | 常见加载器 |
|---|---|---|---|
| **插件** | 服务端 | 不需要 | Paper / Spigot / Leaves |
| **模组** | 客户端 + 服务端 | 需要 | Forge / Fabric / NeoForge |

简单说：**插件装在服务器上，模组装在玩家自己电脑上。**
